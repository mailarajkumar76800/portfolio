# Maila Rajkumar Portfolio

Static responsive portfolio based on the supplied reference portfolio, with Rajkumar's details and the AI Project Builder project.

## Files
- index.html — all portfolio content
- style.css — responsive styling
- script.js — mobile navigation + reveal animation

## Edit before publishing
In `index.html`, replace the temporary email/phone and LinkedIn/GitHub URLs if needed.

## Publish on GitHub Pages
1. Create a GitHub repository (for example `portfolio`).
2. Upload `index.html`, `style.css`, and `script.js`.
3. Repository Settings → Pages → Deploy from branch → `main` / root.
4. Open the generated GitHub Pages URL.
